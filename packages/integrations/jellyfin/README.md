# Jellyfin integration

Configure the server's base URL (including any reverse-proxy path prefix), a Jellyfin user access token, and that user's ID. The library refresh runs every 15 minutes.

The integration imports audio, movie, and episode items into the Jellyfin Library App so their entries open the Jellyfin details page from Dashwise. Dashwise no longer provides a built-in playback pipeline for these resources.
